# Deutschkurs Karteikasten

Flashcard app for the vocabulary (Wortschatz) from my intensive German course protocols.

- Open the app on iPhone in Safari, then Share → "Add to Home Screen". Works offline.
- New lesson: "+ Unterricht hinzufügen" and pick the PDF protocol. It is read on the device.
- Progress is stored on the device; use "Backup speichern" now and then.
